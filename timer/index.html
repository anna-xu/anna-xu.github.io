📊 Data Visualization Help

🎯 What is Data Visualization?

Track your timer progress over time by inputting timer data with dates and generating interactive charts. Perfect for monitoring workout improvement, study consistency, or any routine progress.

📝 Data Format

Use this format for your timer data (with example below):

// Optional comment for chart caption
date: "YYYY-MM-DD"
[
  {"label": "Exercise Name", "time": "duration", "notes": "optional_number_or_text"},
]

Comments: Lines starting with "//" become chart captions

📈 Chart Logic

  • X-axis: Dates from your timer data (automatically sorted)
  • Y-axis: If "notes" contains a number, plots that value. Otherwise, plots time duration
  • Lines: Each exercise label gets its own colored line for progress tracking
  • Tooltips: Hover over data points for detailed information
  • Captions: Comment lines appear above the chart

🛠️ Controls

  • 📈 Generate Chart: Create visualization from your data
  • 🗑️ Clear Chart: Remove the current chart display
  • 🧹 Clear Data: Delete all timer data (with confirmation)

🔗 Workflow Integration

Seamlessly connected to your timer sessions:

  • Auto-Generate Data: Complete timers in other modes automatically create data
  • Timer Complete Modal: Use "📊 Create Visualization Data" after completing timers
  • Direct Addition: "➕ Add to Visualization" button adds data here instantly
  • Smart Replacement: First addition replaces example data, subsequent additions append

💡 Tips for Best Results

  • Consistent Naming: Use the same exercise names across different dates
  • Progress Tracking: Put numeric values in "notes" field (weights, reps, scores)
  • Date Format: Must be YYYY-MM-DD (e.g., "2025-01-15")
  • Time Formats: "30s", "1m 30s", "2 minutes", or just numbers (seconds)
  • Multiple Sessions: Add multiple date entries to see progress over time

📊 Example Use Cases

  • Strength Training: Track weight progression in "notes" field
  • Cardio Improvement: Monitor duration increases over time
  • Study Habits: Visualize focus session consistency
  • Flexibility: Track hold times for stretches and poses
  • Skill Practice: Monitor practice session lengths and repetitions

Simple Mode is perfect for basic interval training with work and rest periods. Set your times, choose cycles, and start your timer!

🔧 Custom Mode Help

🎯 Overview

Custom Mode offers advanced timer creation with two powerful tools: the visual Timer Builder and flexible JSON Editor.

🔧 Timer Builder

  • ➕ Add Interval: Create custom exercises with specific durations
  • Labels: Name your exercises (e.g., "Push-ups", "Rest", "Squats")
  • Time: Set duration using formats like "30s", "1m 30s", "2 minutes"
  • Notes: Optional field for tracking (reps, weight, etc.)

📝 JSON Editor

You can also edit the JSON directly to create your own timer for further customization, like creating multi-day routines.

  • Direct JSON Input: Paste or type timer data in JSON format

📅 Day Feature - Advanced

🎯 What is the Day Feature?

The Day feature lets you create multi-day timer routines in a single JSON file and load specific days on demand. Perfect for weekly workout plans, study schedules, or progressive training programs!

📝 JSON Structure

Structure your JSON as an array of day objects:

[
  {
    "day": 1,
    "intervals": [
      {"label": "Push-ups", "time": "30s"},
      {"label": "Rest", "time": "15s"},
      {"label": "Squats", "time": "45s"}
    ],
    "cycles": 3
  },
  {
    "day": 2,
    "intervals": [
      {"label": "Burpees", "time": "20s"},
      {"label": "Rest", "time": "10s"},
      {"label": "Cardio", "time": "2m"}
    ],
    "cycles": 4
  }
]

🚀 How to Use

  1. Paste your multi-day JSON into the JSON textarea
  2. Enter a day number (1, 2, 3, etc.) in the Day field
  3. Click "Load Timer" - only that day's routine will load
  4. Leave Day empty to load single-day JSON normally

💡 Use Cases

  • Weekly Workouts: Day 1 = Monday, Day 2 = Tuesday, etc.
  • Study Plans: Different subjects for each day
  • Progressive Training: Increasing intensity over time
  • Work Schedules: Different task timing for different days
